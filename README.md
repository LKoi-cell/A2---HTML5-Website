# The Red Rose 🌹

## Project purpose
This is a simple HTML5 website created for the A2 website project. It introduces the red rose, explains its symbolism, and provides basic care tips.

## Features
- Semantic HTML5 structure
- Responsive layout for desktop and mobile
- Separate CSS stylesheet
- Accessible navigation and image alternative text
- Sections for information, meaning, care tips and a closing quotation

## How to use
Open `index.html` in a modern web browser. No server or external libraries are required.

## Files
- `index.html` — main webpage
- `css/style.css` — website styling
- `images/red-roses-bouquet.jpg` — uploaded red rose bouquet JPEG
- `images/red-rose-closeup.jpg` — uploaded red rose close-up JPEG

## Publishing
The site can be published using GitHub Pages. After pushing the repository to GitHub, enable **Settings → Pages → Deploy from a branch**, select the main branch and root folder.

## HTML validation evidence
The HTML should be checked using the W3C Nu HTML Checker:
https://validator.w3.org/nu/

Validation evidence can be submitted as a screenshot or saved result showing the final `index.html` validation status. The page uses standard HTML5 elements and is designed to avoid validation errors.
